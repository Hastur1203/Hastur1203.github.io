# 汎用LP一括生成指示書 (配色全変数化・完全決定版)

**プロジェクト名：EMOTION LAB**  
**制作用AIエージェント：GitHub Copilot（VS CodeのAgentモードを想定）**

## 1. テーマ・デザインイメージ・レイアウト指定
- 【選択テーマ】: 感情を香りに変換する架空のフレグランスブランド「EMOTION LAB」のシングルページLP。感情、記憶、余韻を香りとして再構築する実験的なブランドを表現する。
- 【参考サイト (URL)】: https://elementaromalab.com/ （香りをアートや物語として表現するコンセプトを参考にする。文章・画像・ロゴ・既存デザインはコピーしないこと）
- 【参考イメージ (雰囲気)】: 黒・チャコールグレーを基調に、シルバーや淡いラベンダーを差し色にした、静かで幻想的なラボラトリーの世界観。大きな欧文見出しと広い余白を使い、実験的でありながら高級感のあるエディトリアルデザインとする。派手な装飾やポップな配色は避ける。
- 【レイアウト指定】: 「ヒーロー左右2カラム配置」＋「カードを3列のグリッド配置」。ヒーローは左にコピー、右にメインビジュアル。特長・商品はPCで3列、スマートフォンでは1列を基本とする。

## 2. フォルダ構成・ファイル仕様
- 以下のファイル・フォルダ構造で作成し、外部CSSライブラリ・JavaScriptライブラリ・フレームワークは使用しないこと。
  - `index.html` (プロジェクト直下)
  - `css/style.css`
  - `js/script.js`
- `index.html` 内で `css/style.css` と `js/script.js` を読み込むこと。JavaScriptは `defer` を指定し、Vanilla JavaScriptを使用すること。
- GitHub CopilotのAgentモードで作業する場合は、上記3ファイルを作業フォルダ内に直接作成・編集すること。

## 4. デザイン・CSS仕様 (生徒カスタマイズ前提)
- Google Fontsから以下の2種類のフォントを`index.html`の`<head>`内で読み込み適用すること。
  - 欧文フォント：**Cormorant Garamond**（ブランド名・欧文見出し）
  - 和文フォント：**Noto Sans JP**（日本語本文・UIテキスト）
- `css/style.css` 冒頭の `:root` に以下の基本変数を定義し、役割が分かる説明コメントを付与すること。
  - `--font_en`: `"Cormorant Garamond", serif`
  - `--font_ja`: `"Noto Sans JP", sans-serif`
  - `--font-family`: `var(--font_en), var(--font_ja)`
  - `--primary-color`: `#c8c1d9`（ラベンダーグレー）
  - `--secondary-color`: `#8f86a8`（くすみパープル）
  - `--bg-color`: `#111111`（ほぼ黒）
  - `--text-color`: `#f5f3f7`（やわらかな白）
- 欧文見出しは主に`var(--font_en)`、日本語本文は主に`var(--font_ja)`を適用すること。
- 【配色完全変数化ルール】
  - `css/style.css` 内の**すべての配色指定**（背景色・文字色・ボタン・ホバー時・枠線・グラデーション・影など）について、`:root` 外にカラーコードや直接指定のRGB/HSL値を記述しないこと。
  - AIが追加の差し色や装飾用カラーを必要とする場合は、`:root` 内にCSS変数（例：`--accent-color`、`--surface-color`、`--border-color`、`--muted-text-color`、`--hover-color`、`--shadow-color`）を定義し、各セレクタでは必ず`var(...)`経由で適用すること。
  - 生徒が`:root`の値だけを変更することで、ページ全体の配色を比較できるようにすること。
- スマホ表示対応として`@media (max-width: 768px)`のレスポンシブCSSも実装すること。
- ボタンのホバー、カードの浮き上がり（`transform`）、FAQアコーディオンの開閉アニメーションを実装すること。演出は上品で控えめにする。
- HTMLは`header`、`main`、`section`、`footer`などの意味的な要素を用いること。画像には代替テキストを付与すること。
- FAQの開閉は`button`要素で操作できるようにし、`aria-expanded`などの状態を正しく更新すること。キーボード操作と`prefers-reduced-motion`にも配慮すること。

- `placehold.jp` のダミー画像URLを使用すること。**実在する香水ブランドの画像やロゴを流用しないこと。**

  - カード画像：`https://placehold.jp/600x400.png?text=Item`

- ダミー画像は後から生徒が差し替えやすいよう、HTMLまたはJS配列の分かりやすい場所にURLを記載すること。

## 6. 出力ルール
- **GitHub CopilotのAgentモードでは、`index.html`、`css/style.css`、`js/script.js` を作業フォルダ内に直接作成・編集すること。**
- チャット欄にコードを出力する必要がある場合は、**前置き・解説文・まとめの文章は一切出力せず、`index.html`、`css/style.css`、`js/script.js` の完全なコードブロックのみ**をファイル名ごとに出力すること。
- 3ファイル間の読み込みパス・HTML要素のIDやクラス・JavaScriptの参照先が一致し、ローカルでブラウザ表示した際に商品カードと口コミが描画され、FAQが動作する状態にすること。
